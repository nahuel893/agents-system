Enforcement Layers

Layer 1 — Capability Injector (build time)

Builds permitted tool surface from manifest.md + RBAC. Passes to model via bind_tools(). Model cannot see tools outside this list.

Layer 2 — Tool Call Interceptor (execution time)

Before any connector executes: validates call against injected surface. On violation: block + audit log + escalate. Catches hallucinations and prompt injection.
