## Objective and decisions
Persist an accepted Meta message in PostgreSQL before HTTP 200; return 503 if commit fails. After the ACK, processing is recoverable on restart. Sending to WhatsApp is at least once, not exactly once: record/check a per-turn idempotency key before send and document the unavoidable ambiguous-success window.
