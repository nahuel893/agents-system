# Durable webhook delivery — #43, #44, #46

## Objective and decisions
Persist an accepted Meta message in PostgreSQL before HTTP 200; return 503 if commit fails. After the ACK, processing is recoverable on restart. Sending to WhatsApp is at least once, not exactly once: record/check a per-turn idempotency key before send and document the unavoidable ambiguous-success window. Exhausted retries stay visible as failed with audit and escalation; when workers reach capacity, durable pending work waits, never drops.

This inbox/outbox chooses PostgreSQL as the handoff source of truth, not the durable chat-history backend of ADR-002 A.4/G.22 (sometimes called G.4/G.22).
